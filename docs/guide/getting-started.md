# Getting started

## First launch

1. Open TrainMe. If your iPhone uses Face ID, TrainMe asks for it before showing anything. If Face ID doesn't work, tap `Unlock` and enter your passcode.
2. TrainMe shows a reminder that **your data lives only on this iPhone**. There is no cloud backup, so you'll want to export your data regularly — see [Backup and restore](backup-and-restore.md).
   - Tap `Got it` to continue, or
   - Tap `Add yourself as a client` to set up your own profile so you can log your own training.
3. TrainMe asks permission to send notifications. Allow it if you want session reminders.

## What's already in the app

TrainMe starts with a library of 34 common exercises — strength, bodyweight, cardio and mobility — so you can build workouts straight away. You can edit them or add your own from the `Exercises` tab.

## A typical day

1. **Build a workout** once in the `Workouts` tab — see [Workouts and exercises](workouts-and-exercises.md).
2. **Add a client** in the `Clients` tab and run their intake — see [Clients and intake](clients-and-intake.md).
3. **Schedule a session** for them in the `Schedule` tab — see [Scheduling sessions](scheduling.md).
4. **Run the session**: log each set as you go, with a rest timer on your iPhone or Apple Watch — see [Running a session](running-a-session.md).
5. **Check progress** in their reports — see [Progress reports](reports.md).

## Locking

TrainMe locks itself whenever you leave the app, and unlocks with Face ID (or your passcode) when you come back. Your clients' information stays private even if someone else picks up your phone.
